# LLM Deployment Template

This repository demonstrates how to **automatically build and deploy a web app** using **GitHub Actions** and **GitHub Pages**.  
It forms the Round 1 baseline for the *LLM Code Deployment Project*.

---

## 🧱 Project Overview

When a JSON task request is received, the LLM generates an app that:
1. Displays the provided brief (for example, a captcha solver or markdown viewer)
2. Deploys automatically to GitHub Pages
3. Posts its repo and commit info to the instructor’s evaluation API

---

## 🧰 Features

- No manual deployment steps
- Uses official GitHub Actions (`upload-pages-artifact`, `deploy-pages`)
- Works for static HTML, or Node-built sites (`npm run build`)
- MIT License
- Ready for LLM-assisted modification in Round 2

---

## 🔧 How to Deploy

1. Fork or clone this repository.
2. Ensure your default branch is `main`.
3. Commit and push.
4. GitHub Actions will:
   - Detect the repo,
